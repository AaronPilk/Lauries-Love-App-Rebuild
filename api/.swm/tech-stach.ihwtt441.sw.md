# Introduction

This document outlines the core technologies and tools used in our application. Each technology has been carefully selected to provide the best development experience and application performance.

# Core Technologies

## TypeScript

TypeScript serves as our primary programming language, providing:

- Static type checking
- Enhanced IDE support
- Better code maintainability
- Improved debugging experience

## NestJS

Our application is built on NestJS, a powerful Node.js framework that offers:

- Modular Architecture: Organized, scalable backend development with dependency injection
- TypeScript Support: Strong typing and object-oriented programming features
- Versatile Ecosystem: Integrated support for GraphQL, WebSockets, microservices, and ORMs

## TypeORM&nbsp;

We use TypeORM as our Object-Relational Mapping (ORM) tool, providing:

- Flexible database connection management

- Automatic schema generation

- Easy entity relationship management

## PostgreSQL&nbsp;

Our database of choice is PostgreSQL, offering:

- Advanced relational database capabilities

- Robust data integrity and ACID compliance

- High performance and scalability

# Development Tools

## ESLint

Our code quality is maintained through ESLint with:

- Strict TypeScript rules
- Best practices enforcement
- Consistent code style

## Prettier + Unicorn

Code formatting is handled by:

- Prettier for consistent code style
- Prettier-plugin-tailwindcss for class sorting
- eslint-plugin-unicorn for additional best practices

# Cloud Infrastructure

## AWS ECS

Our container orchestration platform enables:

- &nbsp;Scalable and flexible container deployment
- &nbsp;Easy management of containerized applications
- &nbsp;Seamless integration with other AWS services

## AWS ECR

We utilize AWS Elastic Container Registry for:

- &nbsp;Secure and private container image storage
- &nbsp;Simplified container image management
- &nbsp;Automated image scanning and versioning

## AWS Fargate

Leveraging serverless container computing through:

- &nbsp;Automatic infrastructure management
- &nbsp;Pay-per-task container execution
- &nbsp;Enhanced security and resource isolation

## AWS Load Balancer

Implementing intelligent traffic distribution via:

- &nbsp;Dynamic request routing
- &nbsp;High availability and fault tolerance
- &nbsp;Automatic scaling and health checks

## AWS RDS

Our managed relational database service provides:

- &nbsp;Automated database administration
- &nbsp;High-performance and scalable database instances
- &nbsp;Built-in backup and disaster recovery features

# Monitoring and Analytics

## Sentry

Error tracking and monitoring is handled by Sentry:

- Real-time error tracking
- Performance monitoring
- Issue analytics
- Error context and stack traces
