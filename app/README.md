# Laurie's Love

Laurie's Love is a React Native project that underwent significant updates and improvements during the process of upgrading libraries and dependencies. This includes changes in components and how libraries are used, as well as adopting new approaches in several areas.

# Project Installation/Upgrade Instructions

Here are the installation/upgrade steps I usually follow:

1. Run `yarn cache clean && rm -rf node_modules ios/build ios/Pods ios/Podfile.lock android/.gradle android/build/generated/autolinking` to remove old files.
2. Run `npx expo install` to install new dependencies and libraries (usually for iOS).
3. Run `npm run ios/android/start` to start the project (DEVELOPER VERSION with EXPO)

#### Update pods: npx pod-install

#### Update projects(ios/android): npx expo prebuild --clean --platform ios/android/all

If you encounter any issues, please reach out to Vadym Bezsmertnyi.

## Important! Potential Issue!

This project is large, and you may encounter errors during the build process. This seems to be either a bug or a new feature in the latest React Native versions.

### Example Error(They should fix it soon, so we are waiting for the new version with the fixes.):

```
No member named 'enableDoubleTapZoom' in 'facebook::react::RNPDFPdfViewProps'
```

### Steps to Fix the Issue:

You may need to increase the file monitoring limit on macOS. Follow these instructions:

1. **node_modules/react-native-pdf/fabric/RNPDFPdfNativeComponent.js:**:
   As a temporary workaround, or with a patch-package fix, you may change the following line in: node_modules/react-native-pdf/fabric/RNPDFPdfNativeComponent.js
   ```
   enableAntialiasing: ?boolean,
   enableDoubleTapZoom: ?boolean, // add this line
   fitPolicy: ?Int32,
   ```
2. **ios/build/generated/ios/react/renderer/components/rnpdf/Props.h:**
   Then re-run pod install to re-run the code generation. After this, you can confirm the new property was generated by inspecting the file: ios/build/generated/ios/react/renderer/components/rnpdf/Props.h which should now contain:
   ```
   bool enableAntialiasing{false};
   bool enableDoubleTapZoom{false}; // this will now have been added if the codegen works
   int fitPolicy{0};
   ```

## 2. SVG Icon Management

One of the major updates is the overhaul of how local SVG icons are handled. Previously, the project relied on the `react-base` library for icons, which introduced issues after the updates. To address this, the project now uses the `@svgr/cli` library for processing SVG files.

A custom script and template have been implemented to streamline the integration of SVG icons as JSX+TypeScript components, ensuring better compatibility and flexibility for the project. This approach minimizes dependency on third-party icon libraries, which can often be buggy, especially in large projects and React Native environments.

### 2.1. How It Works

1. **Add Icons**  
   Place your SVG icons in the directory:  
   `src/assets/icons-auto/svg`  
   For future convenience, name your icons descriptively, e.g., `icon-arrow-back.svg`. Ensure the icons are universal (e.g., without hardcoded colors) to allow versatile usage.
2. **Run the Command**  
   Use the following command in your terminal to convert the icons:
   ```bash
   npm run icons
   ```

### 2.2. This will:

- Convert the SVG files to JSX+TypeScript components.
- Save the generated components in: src/assets/icons-auto/components
- Use the template located at: src/assets/icons-auto/icon-template.js, which is designed to handle most SVG icons.

3. **Import and Use Icons**
   Import and use the generated icon components in your code. For example:

```TypeScript
import IconArrowBack from 'src/assets/icons-auto/components/IconArrowBack';
const MyComponent = () => <IconArrowBack width={24} height={24} fill="#000" />;
```

The components support various props for SVG customization, making them versatile and easy to style.

_Benefits of the New Approach_

- Independence from Buggy Libraries: By avoiding reliance on external icon libraries, the project becomes more stable and maintainable.
- Customizable Icons: Generated components allow for full customization of SVG properties, ensuring a universal and reusable icon set.
- Streamlined Workflow: Automating the conversion of SVG files into ready-to-use components saves development time and effort.
